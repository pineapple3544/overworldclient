# 로비 자동 접속

별도 모드 없이 [Java Edition Quick Play](https://feedback.minecraft.net/hc/en-us/articles/16499677456781-Minecraft-Java-Edition-1-20-Trails-Tales)의 `--quickPlayMultiplayer` 게임 인자를 사용합니다. 설치된 26.2 버전 메타데이터에서도 해당 옵션을 확인했습니다.

- `config/launcher.json`의 `velocityHost`와 `velocityPort`를 접속 대상으로 사용합니다. 기본값은 `overworld.flyjung.kr:25565`이며 기본 포트는 생략합니다.
- 전용 공식 런처에 `overworld-<기본 버전 ID>` 실행 구성을 만들고 Overworld 설치 설정에서 선택합니다. 바닐라는 원본 버전을 상속하며, Fabric·설치된 로더는 로더의 mainClass·libraries·게임/JVM 인자를 보존한 별도 구성을 만듭니다. 원본 게임 버전 JSON을 변경하지 않습니다.
- 게임 인자로 `--quickPlayMultiplayer overworld.flyjung.kr`을 전달합니다. 공식 런처 실행 인자나 JVM 인자에 넣지 않습니다.
- 게임 시작 후 로비 접속을 시도합니다. 연결 종료 후에는 멀티플레이 목록에 등록된 Overworld로 재접속할 수 있습니다. 게임이 이미 실행 중일 때 접속 명령을 보내거나 반복 재접속하지 않습니다.
- Minecraft 자동 실행 설정을 끄더라도 공식 런처에서 Overworld 프로필을 직접 플레이하면 로비 자동 접속 구성은 적용됩니다.

## 서버 목록

전용 게임 폴더의 `servers.dat`를 Java big-endian NBT로 읽고 서버 이름·주소를 등록합니다. 같은 주소가 있으면 기본 포트·대소문자를 정규화해 중복 추가하지 않습니다. 기존 다른 서버, 아이콘, 리소스팩 허용 설정, 알 수 없는 태그를 보존합니다. 압축된 파일도 기존 압축 형태를 유지합니다.

변경 전 파일은 `.overworld/server-backups`에 보관합니다. 손상된 목록이나 연결된 경로는 덮어쓰지 않습니다. 변경 직전 Minecraft 종료를 재확인하며, 같은 준비 작업의 다른 단계가 실패하면 목록을 복구합니다. 외부에서 변경된 파일은 자동 복구로 덮어쓰지 않습니다.

실행 옵션이나 설치 설정을 처음 바꿀 때는 Minecraft와 공식 런처를 완전히 종료해야 합니다. 평소 사용하던 개인용 Minecraft 폴더는 수정하지 않습니다.

## 검증

서버 목록의 신규 등록·중복 방지·개인 설정 보존·백업·복구·손상 및 실행 중 보호와 바닐라/Fabric 별도 실행 구성을 단위 테스트로 확인합니다. 실제 서버 입장 성공 여부는 학교 계정 연결과 서버 접근 권한에 따라 결정되므로 게임 실행 후 확인해야 합니다.

자동 실행은 Overworld 플레이를 누른 뒤 나타나는 수정된 설치 설정·플레이어 안전 기능 경고의 플레이 버튼까지 처리합니다. 다시 표시하지 않기 설정은 변경하지 않습니다. 로그인, 체험판, 다른 오류는 자동으로 확인하지 않습니다.
